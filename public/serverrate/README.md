# RF NEVERMIND Server Rate

Content-only component for the existing right column of the website. Includes Server Rates, Regen Cash Coin, Vote System, Donation, and New Character Reward. Excludes navbar, sidebar, status panels and footer.

Use serverrate.html as an HTML fragment, serverrate.css as its stylesheet, and serverrate.js as reserved standalone JavaScript (currently no interactions are needed).

Do not paste external scripts into CKEditor; use the website template for CSS/JS loading. GitHub content cannot execute automatically from CKEditor if scripts are stripped.
