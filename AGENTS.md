## Anti-slop rules

Before editing, read [core antislop skill](.agents/skills/antislop/SKILL.md). Use the relevant optional skills in the same folder for UI, copywriting, accessibility, responsive layout, and code. Apply the rules as a filter, not a generic redesign. Use **during** mode for new work and report the delivery gate. Keep user-provided designs unless asked to change them.

Installed from https://github.com/miqdadbadjuber/anti-slop (v3.2.24). Skill files are checked into the repository for project-wide access. For interactive installer setup on an agent's own machine, run `npx antislop-ai` inside this repository and choose **this project**.
